# Portfolio Jaline Mombach Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and locally ship (not publish) the static Astro portfolio of Jaline Gonçalves Mombach described in the spec, with deterministic data sync scripts, accessibility tests and CI workflows.

**Architecture:** Astro 5 static site, zero client JS by default, small vanilla-TS islands for filters / theme toggle / copy buttons. Data comes from two committed JSON files generated by Python scripts (`lattes.py` from the Lattes XML, `repos.py` from the local authenticated `gh` CLI) merged with hand-edited YAML curation. Narrative content lives in Astro content collections validated by Zod. All UI strings go through `t(key)` from `src/i18n/pt.json`. Styling is a neutral token-based baseline so the `impeccable` skill can restyle later without touching structure.

**Tech Stack:** Astro 5.x, TypeScript, Zod, Vitest (TS unit tests), pytest (Python tests), Python 3.12 + PyYAML, PyMuPDF (`fitz`), Playwright + `@axe-core/playwright`, `html-validate`, `@lhci/cli`, GitHub Actions, npm, Node 24.

**Spec:** `docs/superpowers/specs/2026-10-12-portfolio-design.md` (read it fully before starting; this plan does not repeat every sentence of it).

## Global Constraints

- Site is an academic / institutional portfolio. Forbidden anywhere in copy, CTAs, metadata, alt text (case-insensitive, PT and EN): `consultoria`, `consultora`, `contratar`, `contrate`, `cliente`, `serviço`, `serviços`, `orçamento`, `freelance`, `hire`. Allowed vocabulary: "atuação profissional", "colaboração", "parcerias institucionais", "projetos interinstitucionais", "convites para palestras e bancas".
- Never describe any project as paid or client work. Mark unverifiable facts with `<!-- REVISAR: ... -->`; never invent metrics, URLs or DOIs.
- Portuguese only, `lang="pt-BR"`. Astro i18n config: `defaultLocale: "pt-BR"`, `locales: ["pt-BR", "en"]`, `prefixDefaultLocale: false`. Do NOT create EN pages. No hardcoded UI strings in components; use `t(key)`. English terms inside PT text wrapped in `<span lang="en">`.
- Primary nav, in this order on every page, current page `aria-current="page"`: Início `/`, Sobre `/sobre`, Pesquisa `/pesquisa`, Projetos `/projetos`, Colaboração `/colaboracao`. Plus `/acessibilidade` (footer link) and `/404`.
- WCAG 2.2 AA: one `h1` per page, no skipped heading levels, skip link "Pular para o conteúdo" first focusable, contrast ≥ 4.5:1 text and ≥ 3:1 UI/focus in light and dark, focus ring ≥ 2px, target size ≥ 24×24 px (aim 44×44), `prefers-reduced-motion` respected, reflow at 320 CSS px with no horizontal scroll, every `<img>` has `alt`.
- Theme: tokens on `:root` in `src/styles/tokens.css`; dark under `@media (prefers-color-scheme: dark)` guarded by `:root:not([data-theme="light"])` and again under `:root[data-theme="dark"]`; `body` has explicit background; manual toggle persisted in `localStorage` inside try/catch; inline head script prevents flash of wrong theme.
- Filters: full list rendered server-side, JS only enhances; filter state mirrored in URL query (`?tipo=&ano=&tema=&q=`); results announced via `aria-live="polite"` ("12 publicações encontradas"); empty state with "Limpar filtros".
- Contact email `jaline.mombach@iffarroupilha.edu.br`. Profile links: Lattes `http://lattes.cnpq.br/5793944765294091`, LinkedIn `https://www.linkedin.com/in/jalinegm/` (find-me button only), GitHub `https://github.com/jalinegm`.
- Python scripts run as `python -I scripts/<name>.py`; output deterministic (sorted keys, stable order, `\n` newlines, UTF-8, `ensure_ascii=False`). No tokens stored in CI; sync runs locally, outputs committed.
- Original PDFs (`TeseJaline_correcoesProfeFatima.pdf`, `dissertacaoJaline.pdf`) and the Lattes zip stay out of git (already in `.gitignore`; verify). Compressed copies go in `public/docs/` at < 10 MB each.
- Do NOT create or push the GitHub remote. Document the commands in README only. Commit locally in logical commits (conventional commit style).
- Windows host, Git Bash available. `pdftotext` at `/ucrt64/bin/pdftotext`. Use `npm`.

- [ ] **Step 4: Implement i18n**

`src/i18n/index.ts`:
```ts
import pt from "./pt.json";

type Dict = { [k: string]: string | Dict };

export function t(key: string, vars: Record<string, string | number> = {}): string {
  const found = key.split(".").reduce<string | Dict | undefined>(
    (node, part) => (typeof node === "object" && node !== null ? node[part] : undefined),
    pt as Dict,
  );
  if (typeof found !== "string") throw new Error(`Missing i18n key: ${key}`);
  return found.replace(/\{(\w+)\}/g, (_, name) => String(vars[name] ?? `{${name}}`));
}
```
